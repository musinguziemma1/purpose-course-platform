# Image assets

The original project referenced these files without including them. The supplied
replacements are stock photographs from [Pexels](https://www.pexels.com/), provided
under the [Pexels License](https://www.pexels.com/license/). They illustrate the
demo curriculum and community; they do not document actual Purpose Course events,
participants, or faculty.

Files are stored locally, so displaying the website does not depend on requests
to an external photography service. They were downloaded at a width of 1600px.
Keep these filenames when replacing them with the organisation's own photos:
the application and existing database records reference these paths.
